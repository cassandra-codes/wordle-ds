# Cheating at Wordle with Data Science

### Purpose
This project was a fun summer project to see if I could use turn a casual word game into a complicated mathematical problem (spoiler: yes).

### Requirements
* python3
* pip
* virtualenv

### Installation and setup
```
git clone git@github.com:cassieopterix/wordle-ds.git
cd wordle-ds
virtualenv venv
source venv/bin/activate
pip -r requirements.txt
jupyter notebook
```
